# === Настройка безопасной файловой системы ===

Перед началом воспользуемся `nano /etc/fstab`, так как все настройки будем прописывать в этом файле. Он доджен выолядеть следующим образом:  
![{98B10B01-3A3A-4728-9F5D-6F406D44654C}](https://github.com/user-attachments/assets/b87673bb-66ff-4a7b-be73-1ad9c171d86e)

## 1. Изменение файла "fstab"
Изменяем данный файл следующим образом:  
![{5BE5DD06-B092-4EE9-B470-0E76A79164B2}](https://github.com/user-attachments/assets/fd7e1a67-913b-4a22-84fa-d91923d1acd4)

Пройдемся по изменениям более подробно:
- defaults: стандартные настройки (rw, suid, dev, exec, auto, nouser, async)
- rw: режим записи (read-write)
- nosuid: блокирует SUID/SGID биты
- nodev: запрещает использовать устройства ("/dev/...") в разделе
- noexec: запрещает выполнение программ в этом разделе
- relatime: оптимизирует запись времени доступа к файлам
- size=2G: ограничивает размер

После изменений сохраняем и используем команду `mount -o remount -a` для применения изменений. После этой команды используем команду `systemctl daemon-reload`, чтобы система использовала новую версию файловой системы
