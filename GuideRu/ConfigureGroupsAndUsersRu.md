# === Настройка групп и пользователей ===
## 1. Создание групп
Для создания групп откроем файл "group" с помощью команды `nano /etc/group`. В конце файла прописываем `admins:x:1001:`. Пройдемся по данной записи подробнее:
- admins: название группы
- x: пароль (пароль не задан)
- 1001: GID (уникальный числовой идентификатор группы)
- После GID указываются пользователи, которые входят в эту группу (пока в этой группе пользователей нет)

## 2. Создание пользователей
Для создания пользователей откроем файл "passwd" с помощью команды `nano /etc/passwd`. Создадим пользователя, проаисывая в конец файла `viromant:x:1001:1001:x:/home/viromant:/bin/bash`. Пройдемся по данной записи подробнее:
- viromant: имя пользователя (если что, имя пользователя случайное и не с чем несвязанное)
- x: пароль (пароль не задан)
- 1001: UID (уникальный числовой идентификатор пользователя)
- 1001: GID (идентификатор основной группы пользователя)
- x: дополнительная информация (например номер телефон или ФИО)
- /home/viromant: Путь к домашней директории пользователя
- /bin/bash: Командная оболочка (shell), которая запускается при входе

Добавим нового пользователя в группу "admins". Для этого изменим строку `admins:x:1001:` на `admins:x:1001:viromant`.

Создадим для нового пользователя домашнюю дерикторию:
```bash
mkdir /home/viromant
chown viromant /home/viromant 
chmod 700 /home/viromant
```

# Создание группы "script-runners" и пользователя "script-runner"
Создадим группу "script-runners" таким же способом, как и группу "admins":
```bash
script-runners:x:1002:
```

Теперь создадим пользователя "script-runner" таким же способом, как и пользователя "viromant", но изменим для нового пользователя домашнюю дерикторию:
```bash
script-runner:x:1002:1002:x:/opt/scripts:/bin/bash
```

Добавим нового пользователя в группу "script-runners".

Создадим для нового пользователя домашнюю дерикторию:
```bash
mkdir /opt/scripts
chown script-runner:script-runners /opt/scripts
chmod 750 /opt/scripts
```
