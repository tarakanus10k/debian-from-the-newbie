# === Настройка групп и пользователей ===
## 1. Создание групп
Для создания групп откроем файл "group" с помощью команды `nano /etc/group`. В конце файла прописываем `admins:x:1001:`. Пройдемся по данной записи подробнее:
- admins: название группы
- x: пароль (пароль не задан)
- 1001: GID (уникальный числовой идентификатор группы)
- После GID указываются пользователи, которые входят в эту группу (пока в этой группе пользователей нет)

## 2. Создание пользователей
Для создания пользователей откроем файл "passwd" с помощью команды `nano /etc/passwd`.
