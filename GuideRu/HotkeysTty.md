# Горячие клавиши в tty
## 1. Управление процессами
- Ctrl + C: прервать процесс
- Ctrl + Z: приостановить процесс

## 2. Перемещение курсора
- Ctrl + A: переместить курсор в начало строки
- Ctrl + E: переместить курсор в конец строки
- Alt + F: переместить курсор на одно слово вперед
- Alt + B: переместить курсор на одно слово назад
- Ctrl + F: переместить курсор на один символ вперед
- Ctrl + B: переместить курсор на один символ назад

## 3. Редактирование текста
- Ctrl + L: очистить экран (команда `clear`)
- Ctrl + D: удалить символ под курсором
- Alt + T: поменять местами два слова (слово под курсором меняется местами с левым словом)
- Ctrl + T: поменять местами два символа (символ под курсором меняется местами с левым символом)
- Alt + L: перевести символы в нижний регистр (начало: символ под курсором, конец: конец слова)
- Alt + U: перевести символы в верхний регистр (начало: символ под курсором, конец: конец слова)

## 4. Вырезание и вставка текста
- Ctrl + K: вырезать текст от курсора до конца строки
- Ctrl + U: вырезать текст от курсора до начала строки
- Alt + D: вырезать слово от курсора до его конца
- Alt + Backspace: вырезать слово от курсора до его начала
- Ctrl + Y: вставить вырезанный текст из буфера обмена на место курсора

## 5. Дополнение команды
- Tab: дополнить текст команды
- Alt + ?: вывести все варианты дополнения
- Alt + *: вставить все варианты дополнения в аргументы команды

## 6. Поиск команд в истории
- Ctrl + R: начать поиск команд в истории. Нажмите еще раз чтобы двигаться вверх по истории. Нажмите Enter чтобы выполнить найденную команду
- Ctrl + J: вставить найденную команду в терминал, без выполнения
- Ctrl + G: прекратить поиск команд в истории
- Ctrl + P: показать предыдущую запись в истории
- Ctrl + N: показать следующую запись в истории
- Alt + <: перейти к первой записи в истории
- Alt + >: перейти к последней записи в истории
- Alt + N: поиск в прямом порядке (ввести команду и нажать Enter)
- Alt + P: поиск в обратном порядке (ввести команду и нажать Enter)
- Ctrl + O: выполнить команду из истории и перейти к выполнению следующей по списку (работает только в поиске Ctrl+R)
