# Настройка PAM
## 1. Настройка PAM модуля "pam_nologin"
Если вы хотите, чтобы по ssh никто не мог подключаться (кроме рута), то вы должны настройть этот модуль. Переходим в `/etc/pam.d/sshd` и проверяем, подключен ли модуль "pam_nologin". Подключенный модуль должен выглядеть примерно следующим образом:  
![{1A51B5CF-6111-453D-AE3F-56BE8AE044AB}](https://github.com/user-attachments/assets/a7b4d847-2f21-4dcf-ab76-b384d411a244)

Для того, чтобы модуль начал работать, нужно создать файл "nologin" в "/etc".

Перезапускаем sshd и готово. Если вы хотите прекратить работу модуля, то просто удаляем файл "nologin".

## 2. Настройка PAM модуля "pam_access"
Предположим есть группа с пользователями и для этой группы нужно запретить возможность подключения по ssh. Для этого переходим в `/etc/pam.d/sshd` и подключаем модуль "pam_access":  
```bash
account required pam_access.so
```

Далее в `/etc/security/access.conf` прописываем следующее:  
```bash
-:[название группы]:ALL
```

Следующая запись обозначает, что для всех пользователей группы, которую вы указали, будет отказано в доступе при попытке подключения по ssh.

Перезагрузите "sshd", чтобы изменения начали работать.

## 3. Настройка PAM модуля "pam_time"

Например, нам нужно, чтобы пользователь "appadmin" (создание пользователя "appadmin" [тут](/GuideRu/Sudo.md)) не имел возможности подключения по ssh в выходные дни, для этой задачи мы и будем использовать модуль "pam_time". Для этого переходим в `/etc/pam.d/sshd` и подключаем модуль "pam_time":  
```bash
account required pam_time.so
```

Далее в `/etc/security/time.conf` прописываем следующее:  
```bash
sshd;*;appadmin;!SaSu0000-2400
```

Следующая запись обозначает, что подключение по ssh через любой источник запрещено для пользователя "appadmin" в субботу и воскресенье с 00:00 до 24:00.

Перезагрузите "sshd", чтобы изменения начали работать.
